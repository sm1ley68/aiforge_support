# Store Advisor

Клиентский чат и рабочее место менеджера Softline Store для кейса «ИИкузница». React, TypeScript, Vite и Motion.

## Фронтенд

```sh
npm ci
npm run dev -- --host 127.0.0.1 --port 5173
```

Клиентский чат открывается на [/?view=chat](http://127.0.0.1:5173/?view=chat), кабинет менеджера — на [/](http://127.0.0.1:5173/). В кабинете нужен токен из серверного параметра `MANAGER_TOKEN`. Vite по умолчанию проксирует `/api` и `/chats` на `http://127.0.0.1:8000`. Другой адрес API можно задать через `SOFTLINE_API_ORIGIN` в `.env.local`.

Для сборки используйте `npm run build`. В размещённом стенде фронтенд, `/api` и `/chats` должны обслуживаться с одного origin. Если сборку раздаёт FastAPI через `STORE_ADVISOR_DIST_PATH`, кабинет находится на `/advisor`, чат — на `/advisor?view=chat`.

## Бэкенд

В окружении бэкенда установите `.[backend,catalog,privacy]`. Укажите `DATABASE_URL` на выделенную PostgreSQL и выполните `python -m softline_backend`, чтобы применить схему. Для API задайте `MANAGER_TOKEN`, `SUPPORT_HOURS_START`, `SUPPORT_HOURS_END`, `SUPPORT_WEEKDAYS`, `SUPPORT_TIMEZONE` и `SUPPORT_EMAIL`. API и worker должны использовать одну базу и один Commerce-индекс. Подробности запуска есть в README командного бэкенда. [Командный репозиторий](https://github.com/sm1ley68/aiforge_support)

Для работы с каталогом Softline Store обновите индекс командой `python -m softline_backend.catalog_refresh --index /путь/к/commerce.sqlite3`. Для сверки цен с карточками магазина включите `COMMERCE_VERIFY_SITE_CARD=real`.

Для локальной приёмки можно собрать индекс из [тестового каталога](../fixtures/softline/advisor-acceptance.xml) командой `python -m aisupport_ml.commerce.catalog /путь/к/acceptance-catalog.xml /путь/к/commerce.sqlite3`. Укажите индекс в `COMMERCE_CATALOG_INDEX_PATH`, оставьте `POLZA_EGRESS_MODE=disabled`. API запускается через `uvicorn softline_backend.api:app_from_env --factory --port 8000`, worker — через `python -m softline_backend.worker`.

## Сценарии приёмки

- В тестовом каталоге отправьте «КП на 2 упаковки, ID предложения 1001». После отправки появятся количество, сумма, источник и дата снимка. Заполните реквизиты и скачайте HTML-файл КП. После перезагрузки диалога кнопка скачивания остаётся доступной.
- Отправьте «КП на 2 упаковки, ID предложения 1002». Чат показывает предупреждение о поставке и форму контакта. После сохранения контакта видны часы работы и почта, настроенные на сервере.
- В кабинете откройте очередь на проверку. Карточка показывает исходный запрос, переписку, позиции и причину передачи. Ответьте с действием «Ждать ответа клиента», отправьте уточнение из исходной вкладки чата и дождитесь отметки «Ответить» в кабинете. После финального ответа запрос можно закрыть и открыть следующий из очереди.
- После ответа откройте «Опубликовать общее решение», введите общий вопрос, ответ и публичный источник Softline. Спросите этот вопрос в новом диалоге. Там появятся опубликованный ответ и ссылка на источник.

Чат, кабинет и тест агента подключаются к API. При недоступном API интерфейс показывает ошибку подключения.
