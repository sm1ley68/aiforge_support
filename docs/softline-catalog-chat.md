# Softline: чат на реальном товарном фиде

Собрать локальный индекс из предоставленного фида:

```sh
python -m aisupport_ml.commerce.catalog /path/to/Mindbox.yml.gz.xml /path/to/catalog.sqlite
```

Worker создаёт один экземпляр агента. `model` может быть существующим `PolzaIntentModel`. Индекс открывается в режиме чтения, исходный XML агенту при ответе не нужен.

```python
from pathlib import Path

from aisupport_ml.commerce import CommerceAgent
from aisupport_ml.commerce.catalog import SoftlineCatalog
from aisupport_ml.commerce.retrieval import KnowledgeBase
from aisupport_ml.commerce.softline_evidence import CATALOG_KNOWLEDGE

agent = CommerceAgent(
    model,
    knowledge=KnowledgeBase(CATALOG_KNOWLEDGE),
    catalog_index=SoftlineCatalog(Path("/path/to/catalog.sqlite")),
)
result = await agent.reply(conversation_id, message_id, text, state=state, history=history)
```

Worker передаёт доверенные `State` и `history`, затем сохраняет `result.state` и ответ по ID сообщения. Поле `State.catalog_context` хранит параметры подбора, в частности платформы, бюджет и количество узлов. Если состояние сериализуется в JSON, при чтении восстановите `CatalogContext` как вложенный объект, а `shown_offers` как кортеж. Структуры договоров/корзины старого режима не заполняются в каталожном чате.

Клиент получает `outcome`, `text`, `products` и публичные `sources`. В `products` передаются исходные карточки из фида. Цены следует сериализовать строками в десятичном формате. Для пакетов с ценой за узел в тексте указаны единица и расчёт для введённого количества. `handoff` предназначен для интерфейса менеджера и содержит историю, выбранные позиции и контекст подбора.

Схема `softline-catalog-v2` разделяет выбор названного товара, подбор по задаче и вопрос о факте. В запросе «Нужен антивирус для Windows» Windows сохраняется как требование к платформе. В запросе «Нужен Windows Server» это название продукта. Вопрос «А сколько стоит?» использует последнюю однозначную карточку. При нескольких вариантах агент просит артикул. Для проверенного сценария подбора агент спрашивает по одному недостающему параметру.

База знаний отвечает на вопросы о доставке, способах оплаты, скачивании счетов, ключей и закрывающих документов. Сопоставление с проверенными формулировками работает локально. При близких совпадениях с несколькими статьями агент не выбирает ответ автоматически. Ответы содержат ссылки на инструкции, а срок конкретной поставки сверяется по карточке товара. [Условия магазина](https://store.softline.ru/delivery_info/) · [Счета](https://docs.softline.com/ru-ru/lk/invoices) · [Ключи](https://docs.softline.com/ru-ru/lk/fulfillment) · [Закрывающие документы](https://docs.softline.com/ru-ru/lk/closing-documents)

При ответе по единственному утверждённому источнику worker сохраняет в PostgreSQL ID статьи, ID и версию источника. При перезапуске статья восстанавливается из утверждённого источника этой версии. Черновики записываются отдельно по статусу и в выдачу не попадают. Реплики клиента в записи базы знаний не сохраняются.

## Прогон по реальному фиду

```sh
SOFTLINE_CHAT_TEST_INDEX=/path/to/catalog.sqlite python -m unittest discover -s tests -p test_indexed_chat.py -v
```

Тесты проходят через `MockSupport.reply()` и настоящий локальный индекс. Заглушка возвращает только структуру извлечения, вся маршрутизация, карточки, цены и передача менеджеру собираются рабочим кодом.

- `Нужен MDaemon Standard на 50 пользователей` → уточнение, если редакция не подтверждена. `MDaemon Messaging Server на 50 пользователей, без привязки к редакции` → варианты лицензий. `Сколько стоит 19579?` → точная карточка.
- `Нужен MDaemon на 49 пользователей` → ближайший доступный пакет на 50 мест. Можно уточнить, нужна новая лицензия, продление или возобновление просроченной подписки.
- `Хотим защитить почту и файлы на 50 сотрудников` → уточняющие вопросы. `Exchange и Windows Server 2019, локально, 50 узлов, бюджет до 650 тысяч рублей` → базовые лицензии Kaspersky Total Security на 12 и 24 месяца. При `А российский аналог?` контекст сохраняется и добавляется источник о российском происхождении. `Согласуете индивидуальную скидку?` → передача менеджеру.

Агент сверяет распознанное название с каталогом до обращения к Polza. Если фид не подтверждает редакцию, агент сохраняет название и число пользователей. По просьбе сравнить лицензии без фильтра по редакции агент использует сохранённые требования.

Для защиты Exchange и файловых серверов Windows подбираются лицензии одной линейки на 12 и 24 месяца. Проверены пакеты для 25–49 и 50–99 узлов. Указанные цены и наличие относятся к снимку фида. Конкретные версии серверных компонентов сверяются перед покупкой. [Лицензионные диапазоны](https://store.softline.ru/kaspersky/kaspersky-total-security-dlya-biznesa/)

### Резервное копирование рабочих компьютеров

1. «Подберите решение для резервного копирования» → агент уточняет, нужны файлы и папки или образ диска.
2. «Файлы и папки, 10 компьютеров с Windows 11» → агент уточняет место хранения копий.
3. «На внешние диски, бюджет до 100 тысяч рублей» → по фиду от 25.11.2026 подходят Handy Backup Standard `HBS10` за 30 800 ₽ и Кибер Бэкап Стандартная редакция `PCSCNL` за 90 660 ₽ на 10 ПК. В ответе есть цены за одну лицензию и за все компьютеры.
4. «Бюджет до 40 тысяч рублей» → остаётся `HBS10`. Если теперь нужен образ диска, в этом бюджете вариантов нет. При бюджете 60 тысяч появляется Handy Backup Professional `HBP10` за 46 560 ₽ на 10 ПК.

Артикул Handy Backup выбирается по количеству компьютеров. Для сценария с подтверждённой бессрочной лицензией на файлы используется карточка Кибер Бэкап. Подбор проверяет цену, доступность, валюту и тип лицензии в текущем индексе. Серверные, облачные и централизованные конфигурации требуют отдельной проверки. Эти уточнения и расчёты доступны локально, включая случай недоступности провайдера.

[Сравнение редакций Handy Backup](https://www.handybackup.ru/backup-comparisons.shtml) · [Лицензии Handy Backup в Softline](https://store.softline.ru/novosoft/novosoft-handy-backup/) · [Карточка Кибер Бэкап](https://store.softline.ru/cyberprotect/pcs16nl-421471/)

### Планирование проектов и редактирование PDF

- «Нужно управление задачами для 20 пользователей» → агент уточняет версию ОС и сколько компьютеров нужно лицензировать. Для 20 ПК на Windows 11 с бюджетом до 4 млн ₽ в снимке от 25.11.2026 подходит Project Professional 2024, `EP2-07001`, за 3 532 780 ₽ на все компьютеры. [Лицензирование и системные требования Microsoft](https://www.microsoft.com/en-us/microsoft-365/p/project-professional-2024/cfq7ttc0ph40)
- «Нужен российский PDF-редактор на 3 ПК с Windows 11» → годовой и бессрочный PDF Commander Бизнес. Уточнение «Только бессрочная» оставляет предложение `541420`. Для большего количества мест требуется подтвердить применимый ценовой тариф. [Тарифы и ограничения PDF Commander](https://pdf-editor.su/compare-master-pdf-editor.php)

Для этих задач цены и наличие берутся из фида, а совместимость и единица лицензирования из проверенных источников. Свойства задаются записями в `DESKTOP_TASKS`. Запросы к облачной модели при этом не нужны.

Если Haiku недоступен, точные артикулы и короткий вопрос про российский аналог обрабатываются локально. Ограниченный резервный разбор также поддерживает демосценарии MDaemon и защиты почты и файлов. Ошибка провайдера остаётся в `result.trace`. Для непонятного запроса без модели создаётся передача менеджеру.

## Контракт кабинета менеджера и КП

Ручной ответ и публикация общего решения требуют операторского токена или сессии журнала.

- `POST /api/requests/{handoff_id}/reply` принимает `{"text":"..."}`. Ответ остаётся в исходном чате, где `GET /chats/{chat_id}/messages` возвращает его с `author: "manager"`. Повтор с тем же телом возвращает сохранённый ответ. Для подтверждения ранее выданного КП по тому же обращению передайте также `confirmedQuoteTurnId`.
- `POST /api/requests/{handoff_id}/knowledge` принимает `question`, `aliases`, `answer`, `sourceUrl`, необязательный `sku` и обязательный `publicContentConfirmed: true`. История обращения автоматически в статью не копируется. Поиск сравнивает нормализованный вопрос с вопросом и явно заданными формулировками. Для статьи с SKU нужен контекст этой позиции. Ссылки для публикации принимаются с `docs.softline.com` и `store.softline.ru`.
- Отправьте в обычный чат `КП на 2 ПК, ID предложения 473583`. Если в текущем контексте одна подходящая позиция, её ID можно опустить. Для пакета укажите количество упаковок. Ответ успешного хода содержит `quote`, а `GET /chats/{chat_id}/turns/{turn_id}/quote` скачивает HTML из сохранённого снимка. Используйте Bearer-токен чата. Документ не выставляет счёт и не задаёт срок фиксации цены.
- `POST /chats/{chat_id}/turns/{turn_id}/resolution` фиксирует подтверждение результата клиентом. `GET /api/requests/metrics` возвращает число передач, ответов менеджера, автоматических и подтверждённых менеджером КП, подтверждённых клиентом ответов без менеджера и медианы времени в миллисекундах. Автоматические и подтверждённые менеджером КП считаются раздельно. Подтверждение передачи в очередь не считается первой содержательной репликой.
